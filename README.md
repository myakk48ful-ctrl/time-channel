# 🕐 ربات آپدیت عنوان چت تلگرام — نسخه Railway

این نسخه طوری آماده شده که **روی Railway اجرا شود** و دیگر هیچ‌وقت مشکل
اتصال به تلگرام / فیلترینگ / پروکسی نداشته باشی. سرور Railway در دیتاسنتر
خارج از ایران قرار دارد و به `api.telegram.org` دسترسی **مستقیم** دارد.

## ✅ مزیت‌ها
- بدون پروکسی و بدون VPN — خودتان در Railway اجرا می‌شود.
- ۲۴/۷ روشن می‌ماند (حتی وقتی لپ‌تاپت خاموش است).
- توکن و ادمین را از پنل Railway ست می‌کنی (نیازی به ویرایش کد نیست).

---

## 🚀 روش استقرار (Deploy)

### ۱) سورس را به گیت‌هاب آپلود کن
یک ریپازیتوری در گیت‌هاب بساز و **همه‌ی فایل‌های همین پوشه** را در آن آپلود کن:
`bot.py`، `Dockerfile`، `requirements.txt`، `Procfile`.

### ۲) پروژه را در Railway بساز
- وارد [railway.app](https://railway.app) شو (با گیت‌هاب اکانت بساز).
- دکمه **New Project** → **Deploy from GitHub repo** → ریپازیتوری خودت را انتخاب کن.
- Railway خودش `Dockerfile` را پیدا می‌کند و استقرار را شروع می‌کند.

### ۳) متغیرهای محیطی را ست کن
در پنل پروژه برو به **Variables** و این‌ها را اضافه کن:

| نام متغیر | مقدار نمونه | توضیح |
|---|---|---|
| `BOT_TOKEN` | `123456789:ABCdef...` | توکن رباتت (از @BotFather) |
| `ADMIN_IDS` | `123456789` | آیدی ادمین (چندتا را با ویرگول جدا کن) |

> ⚠️ اگر این متغیرها ست نشوند، ربات با مقدار پیش‌فرض (`TOKEN` و `123456789`)
> بالا می‌آید و کار نمی‌کند. حتماً ستشان کن.

### ۴) اجرا
پس از Deploy، لاگ‌ها را باز کن. اگر دیدی:
```
Database ready. Starting background updater...
Polling started.
Updater loop started.
```
یعنی ربات **با موفقیت** بالا آمده و به تلگرام وصل شده است. 🎉

حالا در تلگرام `/start` بزن تا پنل مدیریت بیاید.

## 🔁 به‌روزرسانی پس از تغییر
هر بار کد را به گیت‌هاب push کنی، Railway به‌صورت خودکار **redeploy** می‌کند.

## 💾 ذخیره‌ی دائمی تنظیمات (اختیاری)
دیتابیس `bot.db` روی Railway به‌صورت موقت است و با هر Deploy دوباره ریست
می‌شود (چت‌ها/تنظیمات پاک می‌شوند). اگر می‌خواهی تنظیماتت ماندگار بماند:

1. در Railway یک **Volume** بساز (مثلاً mount روی `/data`).
2. متغیر `DB_PATH` را به `data/bot.db` تغییر بده.
3. Redeploy کن.

اگر نیاز داری، بگو تا راهنمای Volume را دقیق‌تر بنویسم.

---

## 🐳 Docker (اختیاری)
می‌خواهی محلی تست کنی؟ فقط با داکر اجرا کن:

```bash
docker build -t time-bot .
docker run -e BOT_TOKEN="...توکن..." -e ADMIN_IDS="123456789" time-bot
```

## 🔧 رفع اشکال سریع
| مشکل | راه‌حل |
|---|---|
| لاگ خطای «Token is invalid» | متغیر `BOT_TOKEN` را درست ست کن |
| ربات جواب نمی‌دهد | `ADMIN_IDS` باید دقیقاً آیدی عددی خودت باشد |
| Deploy موفق اما خاموش | نوع سرویس را `worker` بگذار یا Dockerfile را نگه دار |
